# GitHub Pages release

Prepared site: `docs/site`. Intended URL: https://selimharfouche.github.io/ghost-beta/.

The website is static: recordings, interactive reports, installation links. Ghost's browser workers and Codex authentication remain local to each developer.

Publish only after the owner approves making `selimharfouche/ghost-beta` public under the included MIT license. The public repository includes reviewed demo evidence and synthetic browser recordings. It excludes `.env`, local runs, dependencies, scratch work, and SDK state.

Use a `gh-pages` branch containing only `docs/site`, then configure GitHub Pages to publish that branch's root. No Actions workflow permission, domain purchase, or subscription is required. Verify the public landing page, video playback, two report links, and source ZIP after deployment.

The source files include an earlier screenshot-replay build script for reproducibility; the active landing video and both active encodings are generated by `scripts/build-recorded-video.js` from continuous footage. Original videos are linked separately.
